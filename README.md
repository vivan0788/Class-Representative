🎓 CR Study Vault — Class Representative Portal

A centralized, responsive, and lightweight academic resource portal designed for engineering students. CR Study Vault helps students easily discover, access, and download study materials such as lecture notes, tutorial sheets, laboratory manuals, lab images, and Previous Year Questions (PYQs).

🔗 Live Demo: "CR Study Vault" (https://class-representative.vercel.app)

---

✨ Features

- 📚 Resource Categorization — Browse notes, tutorials, lab manuals, lab images, and PYQs.
- 🎯 Subject-Wise Filtering — Find resources according to specific engineering subjects.
- 🔍 Instant Search — Search for resources by topic, unit, subject, or keyword.
- ☁️ Google Drive Integration — Access study materials through direct Google Drive links.
- 🛠️ CR Admin Panel — Manage academic resources through the Class Representative interface.
- 📱 Responsive Design — Access the portal on mobile phones, tablets, and desktops.
- 🌙 Modern Dark Theme — Enjoy a clean and student-friendly interface.
- ⚡ Lightweight Architecture — Built with vanilla HTML, CSS, and JavaScript.

---

🔐 Security Note

If the admin panel uses only client-side JavaScript, it should not be considered securely protected. Sensitive credentials must never be stored in frontend code. For secure authentication and resource management, integrate a trusted backend or authentication service.
